C++20 Host User API Reference

Include <northstar.h> for full access to runtime session management, RAII resource handles, math types, scene entities, NVG, and NVS configuration.

1. Session Bootstrap (RuntimeSession)

Northstar::RuntimeSession eliminates manual LoadLibrary / GetProcAddress boilerplate, automatically selects Debug (d suffix) or Release DLLs, validates Northstar_GetAPIVersion() against NORTHSTAR_ENGINE_API_VERSION, and tears down the GPU session deterministically on scope exit. 

Northstar::RuntimeConfig cfg{};
cfg.backend                  = Northstar::BackendAPI::D3D12;
cfg.renderTarget             = Northstar::NativeRenderTarget::FromWindow(hwnd);
cfg.vsync                    = true;
cfg.enableValidationLayer    = false;

Northstar::RuntimeSession runtime;
if (!runtime.Initialize(cfg))
{
    std::cerr << runtime.GetLastError() << "\n";
    return 1;
}
Northstar::NorthstarEngine& engine = runtime.GetEngine();

3. Geometry & Virtual Geometry (Mesh)

Opting into Northstar Virtual Geometry requires setting a single enum field on MeshDesc:

Northstar::MeshDesc meshDesc{};
meshDesc.vertices     = vertices.data();
meshDesc.vertexCount  = static_cast<Northstar::UINT32>(vertices.size());
meshDesc.indices      = indices.data();
meshDesc.indexCount   = static_cast<Northstar::UINT32>(indices.size());
meshDesc.geometryMode = Northstar::GeometryMode::Virtualized; // Or GeometryMode::Standard

auto mesh = Northstar::MakeUniqueMesh(engine, meshDesc);

4. Reflection-Driven Materials (Material)

Material inspects the reflection payload of attached ShaderSet objects across PassType::Geometry, PassType::Shadow, and PassType::Depth, exposing direct by-name setters that automatically write into aligned constant buffer slots: 

Northstar::MaterialDesc matDesc{};
matDesc.geometryShaderSet = geomSet.get();
matDesc.shadowShaderSet   = shadowSet.get();
matDesc.cullMode          = Northstar::CullMode::Back;
matDesc.blendMode         = Northstar::BlendMode::Opaque;

auto mat = Northstar::MakeUniqueMaterial(engine, matDesc);
mat->SetVec4("baseColor", { 0.9f, 0.75f, 0.35f, 1.0f });
mat->SetFloat("metallic", 0.9f);
mat->SetFloat("roughness", 0.2f);
mat->SetTexture("BaseColorMap", albedoTex.get());
mat->SetSampler("LinearWrapSampler", anisoSampler.get());

5. Scene, Camera & Light Ergonomics

All spatial types follow a Left-Handed coordinate convention (+X Right, +Y Up, +Z Forward):

camera->SetPosition({ 0.0f, 5.0f, -12.0f });
camera->LookAt({ 0.0f, 1.0f, 0.0f });

sunLight->SetDirection({ -0.5f, -0.8f, 0.4f });
sunLight->SetShadowResolution(Northstar::LightShadowResolution::Res16384);
sunLight->SetShadowSoftness(Northstar::LightShadowSoftness::MediumSoft);

renderObject->SetTransform(position, rotation, scale);
