Northstar Graphics SDK

GPU-driven Direct3D 12 rendering architecture featuring Virtualized Cluster Geometry (NVG), Sparse Virtual Shadow Maps (NVS), and the Northstar Shading Language (NSL).

Virtual Geometry (NVG)

128-triangle cluster DAGs, 32 KiB compressed virtual page streaming, two-phase HZB occlusion culling, and continuous sub-pixel LOD selection.

Virtual Shadows (NVS)

Demand-driven 2-level sparse page hierarchy supporting 60,000+ shadow views across directional clipmaps, spot cones, and point cubemaps.

NSL Toolchain

Custom shader transpiler and reflection compiler emitting self-contained .nsc binary shader packages during build.

Clean Host C++20 API

Single-include <northstar.h> SDK with RuntimeSession ABI validation, Win32 macro guards, and RAII handles.

Developer Environment Setup & Build

Northstar Graphics separates project configuration from compilation using two root scripts:

Script Purpose
setup.bat Verifies CMake 3.20+, Visual Studio x64 C++20 tools, and vendored third-party SDKs, then generates build\NorthstarGraphics.sln. Does not compile binary shader outputs.
build.bat [release|debug|all|clean] Compiles QuarkDynMath, NSLCompiler, all .nsl → .nsc shader packages directly into build\, NorthstarCore.dll, NorthstarD3D12.dll, and the example applications. 
:: 1. Configure developer environment and generate build\NorthstarGraphics.sln

:: 2. Compile Release and Debug configurations (including .nsc shader packages)

Clean Source Tree Guarantee: Compiled .nsc shader containers are build artifacts. They are never stored in shaders/ or tracked in Git; build.bat and CMake custom targets emit them exclusively under build/generated/ and deploy them next to the built binaries.

Example Applications

  • 01_HelloPBR (HelloPBR.exe): Minimal, self-contained C++20 application demonstrating window creation, RuntimeSession bootstrap, metallic-roughness StandardLit materials, and multi-light Virtual Shadows.
  • 02_VirtualGeometryStudio (VirtualGeometryStudio.exe): Interactive Dear ImGui inspection studio showcasing 1.6M+ triangle procedural Virtual Geometry, HZB culling telemetry, cluster/LOD/page debug visualizations, NVS softness presets, and Assimp 3D model import.
