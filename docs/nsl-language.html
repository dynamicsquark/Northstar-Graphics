Northstar Shading Language (NSL)

A structured, reflection-first shading language compiled by NSLCompiler into target-aligned HLSL and self-describing binary .nsc shader containers.

1. Anatomy of an NSL Shader

Every standalone NSL shader file declares its stage, optional library imports, stage I/O contracts, resource property blocks, and entry function:

STAGE PIXEL

LIBRARY_DECLARATION
{
    Add("NorthstarLibrary/VirtualShadows/VirtualShadows.nsl")
}

INPUT_LAYOUT
{
    Get(CLIP_POSITION)
    Get(WORLD_POSITION)
    Get(WORLD_NORMAL)
    Get(UV0)
}

OUTPUT_LAYOUT
{
    Add(COLOR_TARGET0)
}

PROPERTY Material
{
    Buffer Params
    {
        Add(baseColor) : Vec4  = 1.0 1.0 1.0 1.0
        Add(roughness) : Float = 0.5
    }

    Texture2D Textures
    {
        Add(BaseColorMap)
    }

    SamplerState Samplers
    {
        Add(LinearWrapSampler)
    }
}

PROPERTY Frame
{
    Buffer CameraData
    {
        Get(CAMERA_POSITION)
    }
}

SHADER
{
    STAGE_OUTPUT Main(STAGE_INPUT input)
    {
        STAGE_OUTPUT o;
        Vec4 tex = Sample(Material.Textures.BaseColorMap, Material.Samplers.LinearWrapSampler, input.UV0);
        o.COLOR_TARGET0 = tex * Material.Params.baseColor;
        return o;
    }
}

2. Get(...) vs. Add(...) Binding Semantics

Directive Owner Runtime Behavior
Get(SEMANTIC) Engine Automatically populated by NorthstarCore from active camera, transform, light array, NVS shadow tables, or NVG cluster buffers. Immutable from host material setters.
Add(name) Host Application Exposed on Material and ComputeKernel for host C++ configuration via SetFloat, SetVec4, SetTexture, SetSampler, and SetGPUBuffer.

3. Standard Shader Libraries (shaders/NorthstarLibrary/)

  • NorthstarLibrary/VirtualGeometry/VirtualGeometry.nsl — Umbrella library for decoding compressed virtual geometry cluster headers, vertex attributes, world transforms, and debug visualization modes.
  • NorthstarLibrary/VirtualShadows/VirtualShadows.nsl — Virtual shadow view resolution, toroidal/sparse page lookup, Receiver-Plane Depth Bias, tent PCF, and 16-tap Vogel disk soft shadow sampling.

4. Command-Line Compilation (NSLCompiler)

During build.bat, CMake invokes NSLCompiler automatically. You can also invoke it directly:

build\bin\win64-release\NSLCompiler.exe ^
    --input shaders\StandardLit\StandardLitPS.nsl ^
    --target hlsl12 ^
    --output build\generated\shaders\StandardLit\StandardLitPS_hlsl12.nsc ^
    -I shaders
